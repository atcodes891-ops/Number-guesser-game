# 🎯 Number Guesser Game

A simple Number Guesser Game made using C++.

The computer generates a random number between **1 and 100**, and the player has to guess the correct number.

---

## 🚀 Features

- Random number generation
- Hint system (Too High / Too Low)
- Attempt counter
- Beginner-friendly project

---

## 🛠️ Technologies Used

- C++
- iostream
- ctime

---

## 💻 Sample Output

```text
Enter the guess between 1 to 100
50
Too Low

Enter the guess between 1 to 100
80
Too High

Enter the guess between 1 to 100
72
Congrats !!

Number of attempts is 3
```
